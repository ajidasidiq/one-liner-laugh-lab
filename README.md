A make.fun bounty entry for **One-Liner Laugh Lab** — one short funny line answering a prompt: the excuse a robot vacuum gives after eating a sock.

## The line

> I didn't eat your sock. It applied for asylum in my dustbin, and legally I'm a humanitarian appliance.

The joke turns the vacuum from a clumsy appliance into a deadpan bureaucrat: the sock wasn't eaten, it sought asylum, and the vacuum is just following humanitarian law. Fresh angle, no stock "I thought it was food" excuse, every word working.

## What it does

`main.py` validates the line (1–200 characters, a single line, not only whitespace) and writes it to `/output/entry.txt`, then reads the file back to confirm it matches exactly.

## Run it

Requires Python 3. No dependencies, no network access.

```sh
python3 main.py
cat /output/entry.txt
```
